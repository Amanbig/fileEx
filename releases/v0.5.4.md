# FileEx Release v0.5.4

**Release Date:** October 2026

## 🌟 What's New

### ⚙️ Application Settings & Customization
- **Theme Modes**: 1-click toggle between **Light**, **Dark**, or **System** theme preferences.
- **Typography Sizing**: Adjust font scale between **Small** (13px), **Medium** (14px), and **Large** (16px) with dynamic UI adaptation.
- **Font Families**: Choose between **System Sans**, **Monospace** (code-oriented), and **Elegant Serif**.
- **Explorer Navigation**: Configurable **Single-Click** or **Double-Click** to open folders and files.
- **Hidden Dotfiles**: Toggle `.git`, `.cache`, and other dotfiles visibility on or off.
- **Keyboard Access**: Open settings anytime via `Ctrl+,`, TitleBar gear, or sidebar footer.
- **Reset Defaults**: 1-click reset to restore factory explorer configurations.

### 🖼️ Grid / Card View Mode
- Seamless switcher between **Table View** and **Grid View** with persistent user preference in `localStorage`.
- Responsive icon cards with large colored file icons, hover actions, and selection rings.
- Unified multi-selection synchronized between both view modes.

### 🖱️ Right-Click Context Menus
- **Item Context Menu**: Right-click on any item in Table or Grid mode to Open, Cut, Copy, Copy Path, Rename, view Properties, or Delete.
- **Canvas Context Menu**: Right-click on blank background space to create New Folder, New File, Paste from clipboard, Refresh, or Select All.

### ⌨️ Global Desktop Keyboard Shortcuts
- `Ctrl+C` (Copy), `Ctrl+X` (Cut), `Ctrl+V` (Paste), `Ctrl+A` (Select All), `Ctrl+,` (Settings).
- `Delete` (Delete item), `F2` (Rename item), `Enter` (Open item).
- `Alt+Left` (Back), `Alt+Right` (Forward), `Alt+Up` (Up directory).
- Smart focus detection ensures shortcuts do not conflict when typing inside text inputs.

### 🗂️ Quick Access / Places Sidebar
- Added cross-platform system places:
  - 🏠 **Home** (`~`)
  - 🖥️ **Desktop**
  - 📄 **Documents**
  - 📥 **Downloads**
  - 🖼️ **Pictures**
  - 🎬 **Videos**
  - 🎵 **Music**
  - 💾 **File System Root** (`/` on Linux/macOS, `C:\` on Windows)
- **Custom Bookmarks / Favorites**: 1-click pin/unpin for any folder, persisted in `localStorage`.
- **Collapsible Mode**: Expand (`w-56`) or collapse (`w-14`) sidebar with tooltips.

### 🧭 Navigation & Breadcrumbs
- Interactive **Breadcrumb Path Bar** with 1-click ancestor folder jumps.
- Direct path edit mode with `Enter` / `Escape` keyboard shortcuts.
- Quick **Copy Path** button with visual confirmation.
- **Forward** and **Up one level (`..`)** navigation buttons.

### 🎨 Window Controls & UI Shell
- Modern custom **TitleBar** integrated with Tauri v2 window management (`minimize`, `maximize`/`restore`, `close`).
- Fixed window toggle-maximize permission in Tauri capabilities and added dual-fallback handler.
- Version badge (`v0.5.4`) rendered directly in the TitleBar.
- Filename truncation with ellipsis (`...`) and full-path tooltip hover for long names without horizontal scrolling.
- Window drag region (`data-tauri-drag-region`) and double-click to maximize/restore.
- Default window dimension updated to 1100x720 centered.
- Bottom **Status Bar** with item counts, search filter indicators, and selected file size summaries.
- Replaced fixed-height hacks with dynamic flex layout.

### 🐛 Bug Fixes & Linux Improvements
- Fixed WebKitGTK DRM/GBM buffer creation permission denied errors on Linux (`10de` NVIDIA GPUs) by setting `WEBKIT_DISABLE_DMABUF_RENDERER=1`.
- Updated NPM packages and Rust crates to latest versions.
- Updated release workflow to only trigger builds when a version tag (`v*` or `app-v*`) is pushed.
