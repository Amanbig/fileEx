# FileEx Release v0.1.0

**Release Date:** Initial Release

## 🚀 Highlights
- **Core File Explorer**: Directory navigation, file listing, file size and modified date formatting.
- **File Management Operations**: Create folders, create files, delete items, rename items.
- **Clipboard Support**: Cut, Copy, and Paste operations for files and directories.
- **Modern UI Components**: Powered by Tauri v2, React 19, TypeScript, Tailwind CSS, and shadcn/ui.
- **Theme Support**: Dark mode and light mode theming.
