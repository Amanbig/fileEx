# FileEx Release v1.0.0

**Release Date:** October 2026

## 🌟 What's New

### 🗂️ Quick Access / Places Sidebar
- Added cross-platform system places:
  - 🏠 **Home** (`~`)
  - 🖥️ **Desktop**
  - 📄 **Documents**
  - 📥 **Downloads**
  - 🖼️ **Pictures**
  - 🎬 **Videos**
  - 🎵 **Music**
  - 💾 **File System Root** (`/` on Linux/macOS, `C:\` on Windows)
- **Custom Bookmarks / Favorites**: 1-click pin/unpin for any folder, persisted in `localStorage`.
- **Collapsible Mode**: Expand (`w-56`) or collapse (`w-14`) sidebar with tooltips.

### 🧭 Navigation & Breadcrumbs
- Interactive **Breadcrumb Path Bar** with 1-click ancestor folder jumps.
- Direct path edit mode with `Enter` / `Escape` keyboard shortcuts.
- Quick **Copy Path** button with visual confirmation.
- **Forward** and **Up one level (`..`)** navigation buttons.

### 🎨 Window Controls & UI Shell
- Modern custom **TitleBar** integrated with Tauri v2 window management (`minimize`, `maximize`/`restore`, `close`).
- Window drag region (`data-tauri-drag-region`) and double-click to maximize/restore.
- Bottom **Status Bar** with item counts, search filter indicators, and selected file size summaries.
- Replaced fixed-height hacks with dynamic flex layout.

### 🐛 Bug Fixes & Linux Improvements
- Fixed WebKitGTK DRM/GBM buffer creation permission denied errors on Linux (`10de` NVIDIA GPUs) by setting `WEBKIT_DISABLE_DMABUF_RENDERER=1`.
- Updated NPM packages and Rust crates to latest versions.
- Updated release workflow to only trigger builds when a version tag (`v*` or `app-v*`) is pushed.
