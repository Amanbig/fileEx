# FileEx Release v0.6.0

**Release Date:** October 2026

## 🌟 What's New in v0.6.0

### 🛡️ Enterprise-Grade Error Handling & Recovery
- **Global Application Error Boundary**:
  - Implemented a React Error Boundary wrapping the desktop interface.
  - If any unexpected render or runtime error occurs, FileEx gracefully presents an elegant error card with diagnostics, a **"Reload FileEx"** button, and a **"Reset to Home"** session recovery option instead of crashing into a blank screen.
- **Robust File & Directory Operations in Rust**:
  - **Filename Character Validation**: Enforces strict filename validation preventing empty names, directory traversals, path separators (`/`, `\`), null characters (`\0`), and Windows-forbidden characters (`< > : " | ? *`).
  - **Circular Copy & Move Protection**: Actively detects when attempting to copy or move a folder into itself or any of its descendants, blocking infinite recursion with a clear error notification.
  - **Duplicate Copy Auto-Naming**: Pasting duplicate items into the same directory or conflicting locations automatically generates unique non-conflicting names (e.g. `filename (copy).txt`, `photos (copy 2)`) rather than dropping or failing silently.
  - **Cross-Filesystem Move Resilience**: Handles `EXDEV: Cross-device link` errors by automatically falling back to recursive copy + source deletion, enabling seamless moves across drives, USB sticks, and mount points.
  - **Human-Readable OS Error Messages**: Replaced raw I/O error codes with clear user-friendly reasons (e.g. `"Permission denied. Check write permissions."`).
  - **Protected File Deletion**: Clears read-only file attributes before deletion so locked files can be removed cleanly.

### 🎨 Ambient Window Shadow & Surface Color Hierarchy
- **Desktop Window Shadow**:
  - Enabled native window drop-shadows via Tauri window configuration (`"shadow": true`).
  - Added a dynamic window layout shell that tracks floating vs. maximized window states:
    - **Floating**: Renders a crisp 1px framing border (`border border-border/80 dark:border-white/15`) with a deep ambient shadow (`shadow-[0_12px_40px_rgba(0,0,0,0.18)] dark:shadow-[0_20px_60px_rgba(0,0,0,0.85)]`), making the window pop cleanly against desktop wallpapers and other open applications.
    - **Maximized**: Automatically sheds outer borders and shadows to occupy the entire display without edge clipping.
- **Distinct Surface Hierarchy & Contrast**:
  - Refined color scales in `App.css`:
    - **Main Canvas (`--background`)**: Deepened in dark mode (`oklch(0.125 0.008 260)`) and softened in light mode (`oklch(0.985 0.003 260)`).
    - **Places Sidebar (`--sidebar`)**: Distinct tone with rightward-cast depth shadow (`shadow-[1px_0_6px...]` / `dark:shadow-[3px_0_12px...]`) and vibrant active indicators.
    - **Header & Toolbars**: Elevated surface styling with backdrop blur and bottom boundary shadows.
    - **Breadcrumb Address Bar**: Styled as a recessed pill input (`bg-card/90` with inner shadow).
    - **Grid Cards**: Enhanced with physical card depth, subtle border outline, and interactive hover elevation (`shadow-xs hover:shadow-md hover:-translate-y-0.5`).

### 🔘 High-Contrast Interactive Hover & Focus Feedback
- **TitleBar Window Controls**:
  - **Close Button**: Now highlights with a vivid red background (`hover:!bg-red-500 hover:!text-white dark:hover:!bg-red-600 dark:hover:!text-white`) and focus ring, matching native OS behavior.
  - **Minimize, Maximize/Restore & Settings**: Upgraded with high-contrast translucent overlays (`hover:bg-black/10 dark:hover:bg-white/15` and `focus-visible:bg-black/10 dark:focus-visible:bg-white/15`).
  - **Theme Toggle**: Synchronized button size (`h-7 w-8`) and added visible hover overlays.
- **Global Button Variants**: Upgraded ghost and outline button variants so all toolbar actions (New Folder, New File, Cut, Copy, Paste, Delete, Terminal, Column dropdowns) light up with high contrast on hover and keyboard navigation.

### 🐛 Bug Fixes
- **Ctrl+V Parameter Resolution**: Fixed a parameter mismatch in `commandsPallet.tsx` where snake_case keys were passed instead of Tauri's expected camelCase keys (`sourcePaths`, `destinationPath`), resolving the `"not complete arguments passed"` error on paste.
- **GitHub Release Notes Automation**: Enhanced `.github/workflows/release.yml` with dynamic changelog extraction from `releases/v*.md` and `RELEASE_NOTES.md` via multiline GITHUB_OUTPUT streams.
