# FileEx Release v0.6.2

**Release Date:** November 2026

## 🌟 What's New in v0.6.2

### 🖼️ In-App Image Preview & Grid Thumbnails
- **Built-in Image Preview Modal**:
  - Opening any image file (`.jpg`, `.jpeg`, `.png`, `.gif`, `.webp`, `.svg`, `.bmp`, `.ico`, `.avif`) launches a fast in-app lightbox preview instead of immediately spawning an external process.
  - Includes zoom controls (`+`, `-`, `0` to reset), image resolution and file size metadata, keyboard-accessible Previous/Next navigation (`←` / `→`), and an **Open App** button to launch the OS default viewer.
- **Grid View Thumbnails**:
  - Grid cards now render live image thumbnails via Tauri's `assetProtocol` (`protocol-asset`) with automatic fallback to file icons on load error.
- **Context Menu Actions**:
  - Added **Preview Image** and **Open with Default App** options for image files in both Table and Grid context menus.

### 🖱️ Unified Click & Hover Behavior for Files & Folders
- **Consistent `clickMode` Support**:
  - Fixed Table and Grid views so the **Single Click** vs **Double Click** setting applies identically to both **files** and **folders**.
  - In **Single Click** mode, hovering over either a file or folder displays the hover underline (`group-hover:underline`) and opens it on click, while checkboxes and `Ctrl`/`Cmd`/`Shift` clicks continue to toggle selection.
  - In **Double Click** mode, single-clicking selects the item and double-clicking opens it.

### ⚡ Memory & Resource Optimizations
- **Non-Blocking Rust Filesystem I/O**: Moved `list_directory` and `get_item_properties` onto `tokio::task::spawn_blocking` so large directories never stall Tauri's async IPC runtime.
- **Reduced Sort Heap Allocations**: Replaced per-comparison `to_lowercase()` allocations in directory sorting with `sort_by_cached_key`.
- **Thumbnail & Render Memory Caps**:
  - Capped inline Grid thumbnails at 15 MB (`MAX_INLINE_THUMBNAIL_BYTES`) with `decoding="async"` and `loading="lazy"`, and cleared thumbnail error caches on directory navigation.
  - Memoized TanStack Table `columns` definitions and added CSS `content-visibility: auto` to Table rows and Grid cards to skip off-screen layout and paint work.
