# Security Policy

## Supported Versions

We actively support and provide security updates for the following versions of FileEx:

| Version | Supported          |
| ------- | ------------------ |
| 0.6.x   | :white_check_mark: |
| 0.5.x   | :white_check_mark: |
| < 0.5.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within FileEx, please follow these steps:

1. **Do not create a public issue**: Please do not open a public GitHub issue for security-sensitive bugs.
2. **Email the maintainers**: Send an email describing the vulnerability, affected versions, and steps or proof-of-concept to reproduce to [amanpreetsinghjhiwant@outlook.com](mailto:amanpreetsinghjhiwant@outlook.com).
3. **Response time**: We will acknowledge your report within 48 hours and work on a fix as promptly as possible.
4. **Disclosure**: Once a patch is released, we will publicly credit you (if desired) and describe the vulnerability in the release notes.
